# DRCE-LOC — апробация на OpenCV/C++

Реализация алгоритма из статьи:
Zhu Y. et al. "A Low-Delay Dynamic Range Compression and Contrast Enhancement
Algorithm Based on an Uncooled Infrared Sensor with Local Optimal Contrast",
Sensors 2023, 23, 8860.

## Файлы
- `drce_loc.hpp` / `drce_loc.cpp` — класс `DRCELOC`, шаги 1–8 алгоритма (Fig. 2 статьи).
- `main.cpp` — демо: загрузка изображения (или синтетическая 14-битная сцена),
  прогон алгоритма, сравнение с линейным AGC и CLAHE, метрики RMS/Entropy/Tenengrad
  (Section 3.1 статьи), сохранение промежуточных слоёв (dbg_*.png) для отладки.

## Сборка

### Вариант 1: напрямую
```bash
g++ -O2 -std=c++17 main.cpp drce_loc.cpp $(pkg-config --cflags --libs opencv4) -o drce_loc_demo
```

### Вариант 2: CMake
```bash
mkdir build && cd build
cmake ..
make -j
```

## Запуск
```bash
./drce_loc_demo путь/к/ик_кадру.png     # 8/16-бит, одноканальное
./drce_loc_demo                          # без аргумента — синтетическая тестовая сцена
```
LD_PRELOAD=/lib/x86_64-linux-gnu/libpthread.so.0 ./drce_loc_demo
## Ключевые параметры (DRCELOC::Params), соответствие статье

| Поле              | Формула статьи | Рекомендация статьи      |
|-------------------|----------------|---------------------------|
| blockRows/Cols    | X, Y (Step 1)  | блок ≈ 64×64 px            |
| bias              | Bias, Eq. 1    | 128–384                    |
| delta2            | δ², Eq. 2–3    | ≥ (M/X)·(N/Y)               |
| guidedRadius/Eps  | w, ε, Eq. 4    | окно 5×5 (radius=2)        |
| lambda            | λ, Eq. 5       | 128–384                    |
| k1                | k1, Eq. 6      | 1.0                        |
| k2                | k2, Eq. 6      | 0.2–0.7                    |
| gLow/gHigh, dde   | Eq. 7–8        | не заданы явно в статье — см. комментарий в drce_loc.hpp |

**Важно:** `normalizeInputTo255=true` по умолчанию — входные данные (даже 14/16-бит)
линейно нормализуются в диапазон 0..255 перед блочной статистикой, т.к. диапазоны
Bias/λ (128–384) из статьи заданы именно для этой шкалы. Без этого шага параметры,
подобранные авторами, не переносятся напрямую на сырые данные АЦП.

## Известные упрощения относительно статьи
1. **Eq. 7 (шумовая маска детального слоя)** — статья ссылается на внешний
   источник для точного вида функции и не приводит её полностью. Реализована
   типовая интерпретация принципа "меньше гейн в однородных зонах, больше —
   в детализированных", управляемая параметрами `gLow`/`gHigh`.
2. **Aппаратные оптимизации FPGA (Section 3.2)** — использование 16 из 25
   соседей в окне guided filter, LUT для экспоненты, фиксированная точка —
   не воспроизведены, т.к. это чисто hardware-специфичные оптимизации,
   не влияющие на результат при software-реализации в float.
3. Разделимость Gaussian upsampling (Eq. 2–3) реализована через `cv::gemm`
   (см. комментарий в `drce_loc.hpp`) — даёт точный (не приближённый)
   результат формулы, но быстрее наивного O(M·N·X·Y).



# Параметры настройки алгоритма DRCE‑LOC для адаптации к типу сцены
В статье приведены несколько ключевых параметров, которые влияют на баланс между локальным и глобальным контрастом, подавлением шума и ореолов, а также на сохранение мелких деталей. Ниже приведён полный перечень настраиваемых параметров с указанием их назначения и рекомендуемых диапазонов, а также рекомендации по адаптации к трём типовым сценариям (насыщенная сцена, сцена с малыми целями, слабоконтрастная внутренняя сцена).

## 1. Параметры, влияющие на локальный контраст и шум
### Bias (смещение)
Назначение: управляет степенью сжатия локального контраста и подавляет чрезмерное усиление шума в однородных областях. Чем больше Bias, тем слабее локальное усиление и меньше шум, но снижается локальный контраст.
Рекомендуемый диапазон: 128 … 384 (по тексту — оптимально около 256).
Влияние на тип сцены:
Сцены с малыми целями / высоким шумом: увеличить Bias (например, 320–384) для подавления шума на фоне, чтобы цель не тонула в шуме.
Насыщенные сцены с большим количеством деталей: уменьшить Bias (128–192) для усиления локальных перепадов, но следить за появлением шума.
Слабый контраст (интерьер): умеренное значение (около 256) для баланса.

### k1 (коэффициент локального контраста)
Назначение: множитель для локально-контрастной составляющей в уравнении (6). Увеличивает амплитуду локальных вариаций.

Рекомендуемое значение: k1 = 1 (в статье указано, что это даёт лучшие результаты, так как диапазон уже ограничен).

Возможная адаптация: при необходимости можно незначительно увеличить (1.1–1.3) для сцен с очень мелкими деталями, но это может вызвать шум.

### k2 (коэффициент глобального контраста)
Назначение: управляет весом глобальной яркостной карты I_gc в итоговом изображении. Определяет баланс между локальным и глобальным контрастом, а также подавляет ореолы на границах блоков.

Рекомендуемый диапазон: 0.2 … 0.7 (оптимально около 0.5).

Влияние на тип сцены:

Сцены с сильными перепадами яркости (насыщенные): использовать k2 ≈ 0.5–0.7, чтобы сохранить естественный глобальный контраст и избежать ореолов.

Сцены с малыми целями на однородном фоне: можно уменьшить k2 (0.2–0.3), чтобы усилить локальный контраст и выделить цель, но при этом возможны ореолы – их компенсируют увеличением Bias.

Слабый контраст (интерьер): предпочтительнее k2 ≈ 0.5, чтобы не «пересветить» фон, но поднять общую яркость.

## 2. Параметры, связанные с разбиением на блоки и сглаживанием
### Размер локального блока (M/X × N/Y)
Назначение: размер квадратного блока, для которого вычисляются локальные среднее и дисперсия. Меньшие блоки дают лучший локальный контраст, но увеличивают вычислительную нагрузку и могут вызвать мерцание при движении.
Рекомендуемое значение: 64×64 (для видео 1024×768).
Адаптация:
Для статичных сцен с мелкими объектами можно уменьшить до 32×32 – детализация возрастёт, но возрастёт и риск ореолов.
Для динамичных сцен или при ограниченных ресурсах ПЛИС можно увеличить до 128×128 – снизится локальный контраст, но улучшится стабильность.
### δ² (дисперсия гауссова ядра)
Назначение: контролирует кривизну гауссовой интерполяции при повышении дискретизации коэффициентов блоков. Влияет на плавность перехода между блоками и подавление блочного эффекта.
Рекомендуемое значение: δ² ≥ размер блока (например, для 64×64 рекомендуется δ² ≥ 4096; в статье использовали 3600).
Адаптация: при уменьшении размера блока следует пропорционально уменьшать δ². Для более плавных переходов (меньше ореолов) увеличивают δ².

## 3. Параметры глобальной яркостной карты
### λ (константа для глобального усиления)
Назначение: предотвращает чрезмерное усиление глобального контраста (аналог Bias, но для глобальной составляющей).
Рекомендуемый диапазон: 128 … 384.
Адаптация:
Для сцен с очень широким динамическим диапазоном (контрастный пейзаж) увеличить λ (300–384), чтобы избежать «выбеливания» ярких областей.
Для сцен с низким контрастом уменьшить λ (128–200), чтобы поднять общий контраст.
### Bright (желаемая средняя яркость)
Назначение: целевое среднее значение (в 8‑бит) для глобальной яркостной карты (уравнение 5).
По умолчанию: не указано явно, но подразумевается около 128 (средний серый).
Адаптация: можно сдвигать в зависимости от предпочтений оператора (например, для ночных сцен яркость можно понизить до 100, для дневных – до 150).

## 4. Параметры усиления деталей
### DDE (коэффициент усиления деталей)
Назначение: множитель для детального слоя (уравнение 8). Увеличивает яркость высокочастотных составляющих.
Рекомендации: в статье не приведены конкретные числа, но упоминается, что детальный слой адаптивно усиливается с помощью функции маски шума (уравнение 7). Вероятно, DDE можно регулировать в диапазоне 1–3.
Адаптация:
Для сцен с малыми целями и тонкими текстурами увеличить DDE (например, 2–3) для лучшего выделения.
Для сцен с большим шумом уменьшить DDE (около 1) или полагаться на встроенную маскировку шума.
### Параметры маски шума (g_L, g_H)
В уравнении (7) используются g_L и g_H – минимальный и максимальный коэффициенты подавления шума в зависимости от локальной дисперсии. Они не детализированы в статье, но могут быть настроены:
g_L – коэффициент для однородных областей (обычно < 1).
g_H – коэффициент для текстурных областей (обычно = 1).
Адаптация: для шумных сцен уменьшают g_L (например, 0.3–0.5), для чистых – увеличивают до 0.8–1.

## 6. Практические замечания
Для видеопоследовательностей параметры должны быть стабильны от кадра к кадру, чтобы избежать мерцания. Рекомендуется использовать значения из рекомендуемых диапазонов и, если возможно, адаптировать их автоматически на основе анализа гистограммы или дисперсии предыдущего кадра.

В статье подчёркивается, что алгоритм спроектирован с низкой задержкой и эффективно реализуется на ПЛИС, поэтому изменение параметров не должно существенно влиять на производительность (кроме размера блока, который влияет на использование памяти).
